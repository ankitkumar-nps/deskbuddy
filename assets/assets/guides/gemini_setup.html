🤖 AI Assistant Setup

DeskBuddy AI works out of the box using DuckDuckGo + Wikipedia. Add a Gemini API key for smarter, more detailed answers.

1

No setup required for basic search

The AI tab works immediately. Ask about weather, facts, people, history — it uses DuckDuckGo and Wikipedia automatically. No account needed.

Optional: Gemini API for smarter answers

2

Get a free Gemini API key

Go to aistudio.google.com → sign in with Google → click Get API Key → Create API key. Copy the key.

3

Paste it in Settings

Open the Settings tab in DeskBuddy → scroll to AI / Gemini → paste your key and tap Save. The AI tab will now use Gemini first.

4

Test it

Go to the AI tab and ask: "Explain quantum computing in one sentence". If you see the purple Gemini badge on the answer, it's working!

🔑 Free tier limits

Gemini Flash gives 15 free requests/minute and 1 million tokens/day on the free tier — plenty for daily use. The key is stored only on your device.

💡 What each source means

Web DuckDuckGo HTML scrape — most current info

Wikipedia Wikipedia REST API — facts & history

Gemini Google Gemini Flash — intelligent answers

Weather wttr.in — current weather data
